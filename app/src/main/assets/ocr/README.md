# Offline receipt OCR

Tesseract.js 6.0.1 with tesseract.js-core 6.0.0 (LSTM, non-SIMD) and integer English/Portuguese trained data. All files are packaged with the APK: recognition makes no external requests. Libraries and models are Apache-2.0; see LICENSE-tesseract.md and LICENSE-core. Model packages: https://github.com/naptha/tessdata. Exact npm package versions and integrity hashes are recorded in SOURCES.json.

No receipt images or user data belong in this directory.
