# Menatwork brand

Original vector mark: a safety helmet and a W for work, using the app’s warm orange, cream and dark brown. Designed directly in SVG and Android VectorDrawable; no raster image generation.

- menatwork-mark.svg: transparent primary mark.
- menatwork-icon.svg: square icon artwork.
- Android uses an adaptive icon with separate background and foreground; Android 13+ has a monochrome themed icon.
- Header colors adapt to each app theme. Notification icon is a white silhouette.

Keep the symbol centered inside the Android adaptive icon safe area. Do not include small text in launcher icons.
